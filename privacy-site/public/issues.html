How to use this page

Nothing here is a decision. Rows are open questions: each one names what is unknown, what would settle it, and the official context. A row disappears only when the evidence exists privately, not when it is published here.

What would make this page shorter

Each closes one or more rows. None of them should be uploaded to this public site or repository.
