Public-site privacy has limits

This guide has no forms, scripts, analytics, external fonts or uploads. The repository itself is public and contains household-derived data outside this guide; Pages exclusions do not protect repository files. Your browser contacts source sites only when you follow their links; GitHub states that visitor IP addresses are logged for security purposes; see the GitHub source below. The repository remains a separate exposure surface. No private figures were imported into the new illustrative model.

Verification method

Every claim in this edition was re-read on its official page in the audit dated 13 November 2026, and three published statements were corrected as a result. The date beside each source is the applicable check date. Legal facts are distinguished from workflow judgments, missing records and illustrative assumptions. Each data row links to official context; a link is not evidence that the source certifies a forecast, expense or recommendation. Broken candidate URLs were rejected, including the old BOE Prop13 URL and an incorrect Investor.gov path. No live property searches were used.
