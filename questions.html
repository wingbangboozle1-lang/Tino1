Suggested discovery plan — in this order

  1. Have the trust read by an estate attorney (Q01, Q06). Is Property A includible for a basis reset, and does the parent-child test hold? This decides whether selling is nearly tax-free. flag Q01
    Ask for written confirmation of revocable vs irrevocable grantor status.
  2. Inventory the estate (Q02). Add Property A ($3,100,000) + expected 2045 value ($6,531,230) + cash/other assets. Compare to exclusion $24,143,520 per transferor (portability if applicable). Table on Cash page does the arithmetic. flag Q02
  3. Get insurance quotes (U01, U02). CDI comparison tool for 95014 (homeowners) and an agent quote for the 94122 three-unit landlord policy; ask for the earthquake offer. flag U01
  4. Pull actual tax bills for both homes (U03, P03). Read the Tax Rate Area and every fixed charge; confirm whether the $7,000 homeowners exemption is on Property A now. flag U03
  5. Find the solar paperwork for Property A (U05). PG&E permission-to-operate letter + tariff (NEM 1.0/2.0 vs net billing). Keep the $10–$20 credit only if tariff confirms it. flag U05
  6. Confirm Property B rental status (Q04, Q03). Build date vs rent-control cutoff; find its basis and any depreciation already claimed. flag Q04
  7. Re-run with real tax bracket (Q05). Share filing status/income with adviser; Decision page shows how the ranking moves between 12% and 37% federal. flag Q05

    8. When each item arrives, replace its flagged assumption on the relevant page and re-run python3 final/model.py && python3 final/build.py && python3 final/check.py . — the new figure will appear everywhere and stay rounded to $10.
