The 1-Year Prop 19 Clock — Explained Visually

Clock starts: date of death (change in ownership under RTC §60)

  1. Month 0: Death → revocable trust becomes irrevocable → change in ownership occurs → county mails “Change in Ownership” questionnaire.
  2. Within 90 days (best practice): Return PCOR + Affidavit of Death of Trustee to recorder/assessor so they know it’s a parent→child transfer.
  3. Within 1 year: Heir who wants the exclusion must physically occupy Cupertino as principal residence + file BOE-266 (Homeowners’ Exemption). File a forwarding address, register to vote there, update driver’s license.
  4. Within 3 years: File BOE-19-P with assessor (or before selling, whichever first). Late = prospective relief only.
  5. Ongoing: Stay. If you move out, assessor reapplies: FMV at death + inflation adjustments → new bill.
Common trap: Three siblings inherit equally. Only one needs to move in — but only that sibling’s proportional interest keeps the exclusion. The other two interests are reassessed unless they also occupy (separate claims). Buyout vs. co-ownership decision matters. BOE Prop 19 FAQ — co-ownership
