Live vs rent vs sell+invest (Cupertino at inheritance)

SF property kept in all scenarios (income engine). Cupertino rent estimate $7,500/mo (2026) is a planning placeholder — get a broker price opinion. Investment return 7%/yr conservative (historical ~10% nominal).

OptionWhat happensVerdict
A. Live in CupertinoProp 19 partial: tax ~$55,690/yr. No rent income; you get imputed rent (housing value) + lifestyle. SF rent continues.Best if you want to live there; worst pure-return. Tax jump is unavoidable either way.
B. Rent Cupertino, live in SFFull reassessment: tax ~$72,580/yr. Net ~$40,880/yr on $5.44M equity (~0.8% yield) + landlord hassle + SF/Cupertino rent law.Weakest financially. Only if you want to keep the asset for family use later.

Recommendation: Default to C (sell + invest) for maximum profit; choose A (live) only if the non-financial value of living in the family home exceeds ~$275k/yr (the 10-yr return gap annualized). Avoid B (rent) unless you have a specific reason to hold. Keep SF in all cases.

Sensitivities: at 4% home growth / 5% stock return the gap narrows but C still leads; at 2% home growth C leads by more. §121 exclusion ($500k MFJ) can shelter part of the gain if you live there 2 yrs before selling. Investment gains taxed annually (dividends) + at sale — model assumes pre-tax 7%; after-tax ~6% still beats 3% home growth.
