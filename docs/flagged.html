How to Submit a Correction

This site is a GitHub Pages site from the docs/ folder on branch arena/5c7cfaf6-tino1. To request a change:

  1. Open the repo on GitHub → Issues → New issue with title Flagged #X correction and attach a redacted bill/quote (hide APN, name, address).
  2. Or edit docs/ directly and open a PR to main — the site will redeploy on merge.
  3. Update COORDINATION.md — change needs review → done and link the source for manual review.

Privacy reminder: never upload unredacted documents containing personal identifiers to a public repo. Redact APN, owner name, street number, account numbers before sharing.
