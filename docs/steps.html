Inheritance process, step by step (CA trust)

Placeholders: [SETTLOR] = parent, [TRUSTEE] = successor trustee, [BENEFICIARY] = heir. A funded revocable living trust avoids probate. Confirm with CA estate counsel.

  1. Fund the trust now: record deeds transferring both houses into the trust; retitle accounts; name [TRUSTEE]. Unfunded assets still go through probate. CA Courts Self-Help
  2. At death: obtain certified death certificates (6–10 copies); notify [TRUSTEE], banks, insurers, county assessors.
  3. Trustee accepts: successor trustee signs acceptance, obtains EIN for trust, opens trust bank account.
  4. Appraise for step-up: licensed date-of-death appraisal for each house (IRC §1014 basis). Keep report permanently.
  5. File Prop 19 (Cupertino, if live-in): move in ≤1 yr; file homeowner exemption (BOE-266) ≤1 yr; file BOE-19-P ≤3 yrs (before any sale). BOE Prop 19
  6. SF rental: no Prop 19 filing (ineligible). Expect full reassessment; budget new tax. Notify tenants of ownership change; update leases/AB 1482 notices.
  7. Estate tax check: if gross estate >$15M/person, file Form 706 ≤9 mo (6-mo extension via Form 4768); elect portability. Else no filing (unless portability desired). IRS Form 706
  8. Decide (30–90 days): live / rent / sell per Scenarios. If selling: list promptly to capture step-up (~$0 gain).
  9. Distribute: trustee deeds/distributes per trust terms; record deeds; close trust accounts; file final trust tax returns (Form 1041).
  10. Post-transfer: new insurance (primary vs landlord), utilities transfer, solar account (verify NEM status), property-tax appeals window (Prop 8 if value drops).
Deadlines that kill Prop 19: miss the 1-yr move-in/homeowner-exemption or 3-yr BOE-19-P and the exclusion is lost permanently. Calendar them on day one.
