Revocable trust administration — California

How the inherited-property process looks, step by step

Assuming the plan holds: both houses deeded to a revocable living trust (Grantor A, Successor Trustee B, Beneficiary C — placeholders), no probate if funded correctly. Death 2040–2050 triggers trust administration, not probate. Below is the practical timeline with forms, deadlines, and what to file where.
