# Bounded privacy and release audit — 2026-11-12

The existing public repository and numeric Pages edition contain household-specific financial information, including derived quantities. Rounding and noindex are not anonymization or access control. The repository is public; excluding files from Pages does not prevent access via GitHub. Prior commits, PR refs, caches and forks are separate residual risks. The exact contents of those copies were not exhaustively audited. See [GitHub's sensitive-data-removal guide](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) and [Pages visibility guidance](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https).

The corrective edition serves only the separately built public guide and a root redirect. It has invented educational scenarios, not personalized forecasts. Unverified personal amounts remain blank. It contains a question register and a proposed improvements queue; the proposals are not implemented. Existing modeled data and historic editions remain in the public repository, not in the Pages artifact. Changes here cannot erase copies or retroactively guarantee anonymity.
