# Independent audit — 2026-11-11

## Release status: not ready for a privacy-safe release

The published Pages source is the repository root on `main`. The repository and Pages are public. The current landing page and projection pages publish owner-supplied financial facts alongside location and property characteristics. Rounding to $10 and replacing names with roles do not make the combination anonymous. The repository also contains model inputs, generated outputs, older site copies, and prior Git history. A `noindex` tag, an archived label, or removal from navigation does not make a file private. The existing checker tests specific fingerprints, not re-identification risk. Do not claim this publication meets the requested privacy guarantee.

**Change request to the integration/site owner:** remove owner-derived facts and outputs from every publicly served path, including archives and downloadable data. Use independently sourced aggregate or clearly synthetic examples for public illustrations, with no relationship to the owner's actual figures. Assess the repository and history separately; a page-only edit cannot remove past Git commits or copies. Coordinate exposure remediation with the repository owner, including existing clones, caches and GitHub's sensitive-data-removal guidance: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository . GitHub Pages access depends on repository visibility and plan: https://docs.github.com/en/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site . Neither document guarantees third-party cache removal.

## Verification gaps and correction requests

- A source link in a row does not verify every number in it. On the landing page, the property value/assessment row cites county tax-rate pages rather than documentation of those particular values. Owner statements and outputs of a model are not official observations. Projection rows likewise cite the law or a tax-rate book, which does not verify the resulting future amount. Separate sourced rules, unverified owner assertions, and explicit hypothetical calculations; do not label model outputs as verified official values. The user's instruction to leave values blank when not officially confirmed conflicts with displaying personal numerical projections as verified figures.
- The landing page states that selling the already-owned property would tax the *whole gain*. Its adjusted basis and eligibility for exclusions are unknown. See IRS https://www.irs.gov/publications/p523 and https://www.irs.gov/publications/p551 . Request replacement with a conditional explanation.
- The landing page's projected remaining estate-tax room subtracts a modeled house value from a modeled exemption. This is not a verified measure of actual remaining capacity: the IRS states that includible assets, deductions and adjusted taxable gifts matter, and portability may apply. https://www.irs.gov/businesses/small-businesses-self-employed/estate-tax . Request that it be labelled only as a narrow hypothetical, or left blank under the user's verification requirement.
- The existing line-by-line verification claim was not independently reproduced by this audit. The checker confirms link presence and internal checks, not that cited official sources establish every fact or that external links are reachable. Earlier editions contain unresolved source and correctness issues noted in the board; archives remain publicly retrievable.
- One BOE URL tested during this audit, https://www.boe.ca.gov/proptaxes/prop19.htm, returned a BOE not-found page. It was not established that this particular URL occurs in the site; it is not a finding of a broken site link.

## Checks actually performed

- `python3 final/check.py .`: passed structural tests for 20 root pages and model self-tests. This is not a privacy or comprehensive source-verification certification.
- GitHub API reported Pages built from `main` at the base commit and PR #22 merged. This establishes deployment status, not quality or privacy.
- Read the IRS estate tax page and California Controller's estate tax page, https://www.sco.ca.gov/ardtax_estate_tax.html . The IRS identifies estate composition, deductions and adjusted taxable gifts as relevant and lists the 2026 federal filing threshold. The Controller says no California estate tax return is required for deaths on or after 2005; this audit does not extrapolate that wording into a comprehensive statement about every possible local or other jurisdiction's taxes.

This audit does not assert that the full site has been independently verified, or that privacy has been restored. A legal/tax professional should evaluate any actual decision using private records.
