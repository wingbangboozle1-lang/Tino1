Two-home inheritance decision dashboard

Property A (Cupertino, 95014) will pass to the Inheritor through a trust some time around 2040 to 2050. Property B (San Francisco, 94122) is already owned by the Inheritor. This site works out, with an official source on every table row, whether to live in Property A, rent it out, or sell it and reinvest.

Privacy: no names, street addresses, parcel numbers or account numbers appear anywhere on this site. People are "the Transferor" and "the Inheritor". Every owner-supplied and modelled dollar figure is rounded to the nearest $10, which is the disclosure-minimisation control the brief asks for. Rounding is not anonymisation, and this repository is public: options G01 and G02 on the Suggestions page set out the narrower figure-free boundary if you would rather use it.
