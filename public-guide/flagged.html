The two privacy flags, stated plainly

P01 - exact figures in tracked files

The repository's own checker used two exact assessed values as an illustration of the rounding rule, and the coordination log quoted others while describing a privacy fix. A public repository exposes every tracked file. Both have been replaced in this pass. What remains is history, which is P02.

P02 - repository history

Editing a file does not remove it from history. Forks, caches and search indexes may hold copies. Only the owner can decide whether to make the repository private or rewrite history, and either has side effects - a private repository un-publishes nothing that is already copied, and a history rewrite changes every commit identifier.

What this edition did about it

  • Replaced the exact figures with round-number illustrations.
  • Built the published pages from a generator that reads the model output only, so no page can carry a document value.
  • Withheld the current assessed values and the whole bill history, even though the brief asked for them.
  • Added a gate that fails on an address, parcel-number, e-mail or telephone pattern.
  • Labelled every household figure as rounded to $10 and every statutory amount as official.

What it did not do

It did not make the repository private, rewrite history, delete any earlier edition, or publish the bill series. Each of those is an owner decision, and three of the four are irreversible.

Read this page before acting on any number elsewhere. The decision analysis is sound on its assumptions, but several inputs - insurance above all - are placeholders. The recommendation does not depend on them; the level of the result does.

De-identification method. People, the trust, the parcels and the addresses appear only as placeholders and are never published. Household amounts are household or model outputs rounded to the nearest $10 and are labelled as such; statutory amounts are quoted exactly as the official page publishes them and are labelled official. No year-by-year bill history is published. Nothing on this site is legal, tax, investment or insurance advice.
