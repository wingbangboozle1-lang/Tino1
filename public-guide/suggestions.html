Suggestions for review

Proposals, a recommended order, and the changes that would look like improvements and would not be. Nothing here is implemented until it is chosen.

Nothing on this page has been implemented as a result of being listed here. Each row is a proposal with a review status. The Adopt / Hold / Reject controls are browser-only: there is no form, nothing is stored, nothing is submitted, and no choice on this page changes any figure on this site.

Twelve site improvements, and why each one matters

Proposals for review - Adopt means recommended, not implemented
ProposalAreaImpactEffortWhy / what it fixesDone whenStatusOfficial source
S01
Remove the owner's exact bill figures from every tracked file		PrivacyHighLowReplace the exact assessed values and tax bills used as examples in the repository's own checker and coordination notes with round-number illustrations. The live site never showed them, but a public repository is a public file store, and an exact assessed value identifies a parcel.Gate passes and a search of the whole tree for the exact figures returns nothing.AdoptSCC-RATES
S02
Publish the de-identified numeric edition, and keep the no-figures guide		ProductHighMediumThe brief asks for numbers and projections; the published site had none. This edition publishes model outputs rounded to $10 and official amounts exactly, with every row sourced, and links the original no-figures guide rather than removing it.Eight published pages whose every table row links an official page, with a gate that fails on any unrounded household figure.AdoptSCC-P19
S03
Keep the historical bill series out of the published product permanently		PrivacyHighLowA year-by-year assessed value and tax pattern is a fingerprint even when each figure is rounded to $10. The series is not needed to answer any question on this site: the projection uses the current value only.No page contains a year-by-year bill series, and the flagged page records the decision.AdoptRTC-51
S04
Obtain two written insurance quotes for each property		EvidenceHighMediumInsurance is the largest unverified number in the analysis and the one most likely to be wrong. A ZIP-code average is not a price. Quotes must match the actual occupancy: homeowners for A if lived in, landlord for A if let, and a three-unit policy for B.Two quotes per property, recorded privately, with the premium and the exclusions.AdoptCDI-RES
S05
Replace the owner's placeholder premiums and bills with the actual documents		EvidenceHighLowEvery utility and premium figure in the projection is an owner estimate. Replacing them with the last twelve months of bills would turn the projection from a scenario into an estimate without changing a single rule.Twelve months of bills for each property, entered privately, with the projection re-run.AdoptCUP-WATER
S06
Read the solar interconnection agreement before relying on the electricity credit		EvidenceMediumLowThe projection carries a net credit for fifty years. The net-metering tariff that creates it runs for twenty years from interconnection, and a system interconnected today would be on a different, less generous tariff. If the credit ends, electricity becomes a cost.The interconnection date and tariff are known, and the projection stops the credit at the right year.AdoptCPUC-NEM
S07
Have the trust read by an estate attorney and get a written answer to Q01		DecisionCriticalMediumThe basis reset is the whole case for selling. If the home is outside the gross estate, the recommendation changes. No amount of modelling substitutes for reading the document.A written opinion that states whether the home is included and whether the inheritor takes a stepped-up basis.AdoptIRS-INHERIT-FAQ
S08
Write a dated occupancy plan for Property A		DecisionHighLowProposition 19 relief requires the home to become the inheritor's principal residence within one year, and the exemption claim in the same year. Whether the plan is to move in, let it, or sell it, the occupancy intention has to be decided before the transfer, not after.A one-page plan with a date, filed privately with the trust documents.AdoptRTC-63.2
S09
Model estate liquidity, not only estate tax		AnalysisHighMediumThe model computes the tax but not whether the estate can pay it in cash within nine months. For an estate that is mostly a house, that is the binding constraint. Add a liquidity line and an option to sell under time pressure.A liquidity projection by year, with the forced-sale cost shown separately.AdoptIRS-ESTATE
S10
Add a second, independent property-value source		EvidenceMediumLowThe market value of both homes is a single estimate. A second, independent source - an appraisal or a different index - would show how much of the result depends on that one number.A second value for each property, and the difference shown on the decision page.HoldFHFA-SJ
S11
Re-index the Proposition 19 allowance automatically each February		MaintenanceMediumLowThe statute re-indexes the allowance every second February 16. Hard-coding one year's figure would silently go stale. A documented update step, with the BOE letter as the trigger, prevents that.A checklist entry for each odd February, with the published figure recorded.AdoptBOE-LTA-2025-009
S12
Show a confidence band instead of a single line		PresentationMediumHighThe projection is a single path, which reads as more certain than it is. A band built from the 10th and 90th percentiles of the historical replays would communicate the uncertainty honestly.A chart and a table where every projection cell has a range, with the method stated.HoldFHFA-SJ
S13
Add a printable one-page decision sheet		PresentationLowLowThe site is long. A single printable page with the recommendation, the four decisive questions and the numbers would make it usable in a meeting with an attorney or a broker.A one-page PDF-free printable page linked from the overview.HoldIRS-ESTATE
S14
Do not add names, addresses, parcel numbers or account numbers, ever		PrivacyCriticalLowThe site uses placeholders for every person and property. Any future edit that adds a real address or parcel number would undo the whole privacy position and could not be recalled from caches.A gate that fails on an address, parcel-number or e-mail pattern, already enforced.AdoptSCC-P19
S15
Keep the repository public but treat its history as exposed		PrivacyHighMediumExcluding a file from the published site does not hide it in a public repository, and does not remove it from history, forks or caches. The honest options are to make the repository private or to rewrite history, and both are owner decisions with side effects.A recorded owner decision, either way, with the reason.HoldIRS-ESTATE

Record a review decision

These controls are for use during a review. They do not submit anything, they are not stored, and they reset when the page is reloaded. When a decision is made, record it in the project's coordination file so that the next change is deliberate.

What would make this site worse

Five changes that would look like improvements and would not be
Tempting changeWhy it would be a mistakeOfficial source
Adding the exact house value and the exact bill history to make it "more useful"That is the fingerprint. The projection only needs the current value and the rate.SCC-RATES
Rounding harder - to the nearest $100 - to look saferIt changes the arithmetic without changing the fingerprint, and it makes the tax calculations visibly wrong. Rounding is disclosure minimisation, not anonymisation.RTC-51
Removing the assumptions to make the page simplerThe assumptions are the result. A number without its assumption is a claim about the future.IRS-ESTATE
Adding a live calculator that accepts the real addressThe site is public and static. A calculator that asks for an address would collect exactly the data this site refuses to hold.SCC-RATES
Filling in the unverified blanks with estimates so every cell has a numberA labelled blank is information; an invented number is misinformation. The Flagged page exists for this reason.CDI-RES

De-identification method. People, the trust, the parcels and the addresses appear only as placeholders and are never published. Household amounts are household or model outputs rounded to the nearest $10 and are labelled as such; statutory amounts are quoted exactly as the official page publishes them and are labelled official. No year-by-year bill history is published. Nothing on this site is legal, tax, investment or insurance advice.
