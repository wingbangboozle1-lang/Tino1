How this page is used — review before implementing

Nothing on this page is applied automatically. Each row above is a proposed suggestion. The owner (and the attorney/tax adviser) reviews the "Why it helps" and "Official basis" columns, clicks the linked official page to verify the rule, and marks the suggestion as Approved, Declined or Needs more info before any code or model change is made. Approved items are built in a branch, re-checked with final/check.py, and published only after final/check_published.py passes and the pull request is merged. Declined items stay on this page as a record of what was considered and why.

  1. Read the decision suggestions first. Pick the path that matches your housing need and risk tolerance; note the "What must be checked first" flag for each.
  2. Answer the checklist above with the attorney/tax adviser — especially Q01 (trust type), Q02 (cash + portability), and the insurance quotes (U01/U02).
  3. Review the site improvements. For each "Proposed" row, open its official link, decide if the benefit is worth the effort, and note your choice. Only approved rows become work.
  4. Implement on a branch. A session claims the approved rows in COORDINATION.md, edits only its claimed files, and pushes. No session edits another session's scope.
  5. Publish after checks. The branch must pass python3 final/publish.py --check, final/check.py ., jekyll build and final/check_published.py _site before the PR is merged and Pages is confirmed.

All dollar figures on this page are rounded to $10 and come from final/model.py (assumption flag A01) or are quoted exactly from the linked official page (e.g. $1,044,586 Prop 19 cap). No personal address, parcel, or unrounded figure appears. See the Flagged for Review page for every assumption and unconfirmed value.
