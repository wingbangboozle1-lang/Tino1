# Tino1 — Cupertino & San Francisco Inheritance Decision Dashboard

Anonymized decision-analysis site for a 2040–2050 trust inheritance: two CA houses (Cupertino 95014, San Francisco 94122), live vs rent vs sell+invest.

**Live site (GitHub Pages, from `docs/`):** https://wingbangboozle1-lang.github.io/Tino1/

## Contents
- `docs/` — GitHub Pages site (landing + 7 subpages, dashboard, tables, charts, Flagged for Review)
- `data/` — projection CSVs (2026–2050) + scenario comparison (all $ rounded to $10)
- `model/` — reproducible Python model (`project.py`) + assumptions
- `research/` — official-source research notes (tax law, utilities/insurance/market)
- `COORDINATION.md` — shared task board

## Privacy
No personal information on the site — placeholders only. Owner records anonymized.

Every figure links to an official source (Sources page). Unverified items are blank/flagged, never inferred.
