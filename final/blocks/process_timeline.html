Deadline timeline after the Transferor's death

Each clock starts at the date of death. These are legal deadlines, not recommendations - missing one can cost an exemption or add a penalty.

Within 60 days
Trustee serves notice to beneficiaries and heirs; starts the 120-day contest period
Prob. Code §16061.7
Within 150 days
File the change-in-ownership statement for Property A with the Santa Clara County Assessor
R&TC §480
Within 9 months
File Form 706 (estate tax) if above the threshold, or elect portability for a surviving spouse (6-month extension via Form 4768)
IRS Form 706 instructions
Within 1 year
Only if moving in: make Property A the principal residence and file the homeowners' exemption (BOE-266) before the exclusion claim
R&TC §63.2; BOE Pub. 800-1
Within 3 years
Only if moving in: file the parent-child exclusion claim (BOE-19-P) before any transfer to a third party
R&TC §63.2; BOE Prop 19
